# net.or.kr — 디지털 권리 포털

> 망 중립성 · 통신 감청 · 표현의 자유. 한국 인터넷의 검열과 감시, 그리고 우회의 군비경쟁을
> 사건 하나하나 심층으로 해부하는 **비영리 디지털 권리 포털**입니다.

**사이트: https://net.or.kr**

이 저장소는 포털에 서빙되는 콘텐츠의 원본(SSOT)입니다. `main`에 push되면 곧 사이트에 반영됩니다.

## 구성

```
index.html                  포털 랜딩 (주제별 큐레이션 + 읽기 경로)
articles/<slug>/index.html  심층 해설 아티클
```

## 오류 제보 · 보완 제안

모든 글은 출처와 함께 사실관계를 검증하려 노력하지만, 법·정책·기술이 얽힌 주제 특성상
오류가 있을 수 있습니다. **사실 오류, 깨진 링크, 보완 의견은 [GitHub 이슈](../../issues)로
제보해 주세요.** 글은 AI의 보조로 작성되고 사람이 검토합니다.

## 원칙

- 진단 도구나 기술 시연이 아니라, 검열·감시·자유 이슈를 다루는 **콘텐츠 포털**입니다.
- 특정 우회·차단 행위를 권유하지 않습니다. 기술과 법을 함께 읽어 시민이 스스로 판단할
  토대를 만드는 것이 목표입니다.
- 이 포털의 글은 교육·공익 목적의 해설이며 **법률 자문이 아닙니다**.
